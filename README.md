# BUUPASS

BUUPASS is an independent static website prototype combining a Jambojet-based flight interface with BUSCAR-derived bus route search and booking request pages.

## Preview

Open `index.html` locally or deploy this folder as a static site. `vercel.json` includes route rewrites for the flight pages.

The bus and flight schedules, fares, routes, and availability shown here are sample data. Bus booking requests use the WhatsApp number configured in `buses/site-config.js`. Flight booking and payment are not live.

All pages are marked `noindex` while BUUPASS services are being configured. See [BUUPASS-PREVIEW.md](BUUPASS-PREVIEW.md).
